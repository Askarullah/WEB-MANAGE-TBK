Virtual Machine Requirements

WEB TRACK CSID Project Setup Guide

System Requirements

Minimum Requirements

Operating System: Ubuntu 20.04 LTS / Windows 10 / CentOS 8
RAM: 2 GB
Storage: 10 GB free space
CPU: 1 vCPU (2.0 GHz)
Network: Internet connection
Python Version: Python 3.8 or higher

Recommended Requirements

Operating System: Ubuntu 22.04 LTS / Windows 11 / Rocky Linux 9
RAM: 4 GB or more
Storage: 20 GB free space
CPU: 2 vCPU (2.4 GHz or higher)
Network: Stable internet + MikroTik access
Python Version: Python 3.10 or higher

Software Dependencies

Core Python Packages

# Install these packages using pip pip install flask==2.3.3 pip install flask-cors==4.0.0 pip install pandas==2.0.3 pip install openpyxl==3.1.2 pip install paramiko==3.3.1 pip install python-dotenv==1.0.0 pip install werkzeug==2.3.7

System Dependencies

For Ubuntu/Debian:

sudo apt update sudo apt install python3 python3-pip python3-venv sudo apt install build-essential sudo apt install libffi-dev libssl-dev

For Windows:

  • Python 3.8+ from python.org
  • Microsoft Visual C++ Build Tools (for some packages)

For CentOS/RHEL:

sudo yum update sudo yum install python3 python3-pip sudo yum groupinstall "Development Tools" sudo yum install openssl-devel libffi-devel

Virtual Machine Configuration

VM Specifications

Component Minimum Recommended
vCPU 1 core 2+ cores
RAM 2 GB 4-8 GB
Storage 10 GB 20-50 GB
Network NAT/Bridged Bridged (for MikroTik access)

Network Configuration

  • Port Requirements: Port 5050 (Flask app) should be accessible
  • MikroTik Access: VM needs network access to MikroTik devices on SSH port (default 22)
  • Firewall: Allow inbound connections on port 5050 if accessing from other machines

Installation Steps

1. Prepare Virtual Machine

# Update system sudo apt update && sudo apt upgrade -y # Ubuntu/Debian # OR sudo yum update -y # CentOS/RHEL # Install Python and pip sudo apt install python3 python3-pip python3-venv -y # Ubuntu/Debian # OR sudo yum install python3 python3-pip -y # CentOS/RHEL

2. Create Project Environment

# Create project directory mkdir web-track-csid cd web-track-csid # Create virtual environment python3 -m venv venv # Activate virtual environment source venv/bin/activate # Linux/Mac # OR venv\Scripts\activate # Windows

3. Install Dependencies

# Install required packages pip install flask flask-cors pandas openpyxl paramiko python-dotenv werkzeug # Verify installation pip list

4. Setup Project Files

# Create necessary directories mkdir templates static # Create environment file touch .env

5. Configure Environment Variables

Create .env file with the following content:

FLASK_SECRET_KEY=your-super-secret-key-change-this-in-production MAX_CONTENT_LENGTH=52428800 MIKROTIK_SSH_PORT=22 MIKROTIK_USERNAME=admin MIKROTIK_PASSWORD=your-mikrotik-password

6. Create Device Configuration Files

Create devices-active.json:

[ { "name": "Device 1", "ip": "192.168.1.1", "co": "CO001", "location": "Main Office" } ]

Create devices-suspend.json:

[ { "name": "Suspend Device 1", "ip": "192.168.1.2", "location": "Branch Office" } ]

Performance Considerations

Memory Usage

  • Base Flask app: ~50-100 MB
  • Excel file processing: +100-500 MB (depending on file size)
  • MikroTik connections: +10-20 MB per active connection
  • Browser rendering: +200-500 MB

Storage Usage

  • Application files: ~5-10 MB
  • Python environment: ~200-500 MB
  • Excel files: Variable (depends on uploaded files)
  • Logs: ~10-50 MB (over time)

Network Requirements

  • Bandwidth: Minimum 1 Mbps for web interface
  • Latency: <100ms to MikroTik devices for responsive SSH connections
  • Concurrent users: Up to 5-10 simultaneous users (with recommended specs)

Security Considerations

VM Security

  • Keep OS and packages updated
  • Configure firewall (UFW on Ubuntu, Windows Firewall)
  • Use strong passwords for VM access
  • Enable SSH key authentication if using SSH

Application Security

  • Change default Flask secret key
  • Use strong MikroTik credentials
  • Limit network access to required ports only
  • Consider using HTTPS in production

File Permissions

# Set appropriate permissions chmod 755 /path/to/project chmod 644 *.py *.json chmod 600 .env # Keep environment file secure

Troubleshooting Common Issues

Low Memory Issues

  • Increase VM RAM to 4GB+
  • Process Excel files in chunks
  • Limit concurrent users

Network Connectivity Issues

  • Verify VM network adapter settings
  • Check firewall rules
  • Test MikroTik SSH connectivity manually

Package Installation Issues

  • Update pip: python -m pip install --upgrade pip
  • Install build tools if compilation fails
  • Use virtual environment to avoid conflicts

Monitoring and Maintenance

Log Files Location

  • Flask logs: Check console output or configure logging
  • System logs: /var/log/ (Linux) or Event Viewer (Windows)

Regular Maintenance

  • Update Python packages monthly
  • Monitor disk space usage
  • Backup configuration files and data
  • Review security updates

Backup Strategy

Critical Files to Backup

  • app.py (main application)
  • devices-active.json and devices-suspend.json
  • .env file (securely)
  • templates/ directory
  • Any uploaded Excel files

Backup Commands

# Create backup tar -czf backup-$(date +%Y%m%d).tar.gz app.py *.json templates/ .env # Restore backup tar -xzf backup-YYYYMMDD.tar.gz
